Design/analysis drill. Arguments: $ARGUMENTS (default 1 question; 2 if the session is ≥ 60 min).

1. `study next --topic analysis --n <n>` (or a `coding` question that asks for an analysis, if analysis is mastered).
2. `study show ID`, paste the prompt, give the time budget, and open `study answer ID` in the background. Remind them of
   the professor's format: which data structures and why → each step's cost with the reason (cite the STL cost) →
   total, average vs worst where hashing is involved, multi-variable bounds, tight bound.
3. Grade strictly with `study show ID --answer` and the rubric: a right total with missing justification loses most of
   the points, like on the real exam. Show the model answer side by side with theirs (`study viz costs` if they
   misjudged a container cost). Record + weak spots per CLAUDE.md.
